# MTEC 3501 — Assignment 2.2: Research and Project Setup

**Assigned:** Week 2  
**Due:** Week 3

## Purpose

Week 2 begins the research infrastructure for your Culmination Project. You will move the Zotero account you established during Week 1 into the shared MTEC 3501 research environment, create an organized collection for your project, and save an initial source. Project tracking through GitHub Issues and Project Boards will be introduced next week.

This is exploratory research. You are not expected to complete formal precedent research or settle your project concept yet.

## Before You Begin

Complete Week 1 onboarding first, including submission of your Zotero handle through the Onboarding Information Form. Your instructor will add you to the [MTEC 3501 Zotero Library](https://www.zotero.org/groups/5864194/mtec-3501) when availability permits.

If you have not yet received an invitation, complete the parts below that you can and return to shared-library setup after the invitation arrives.

## Required Tasks

### 1. Join the Shared MTEC 3501 Zotero Library

1. Check the email address associated with your Zotero account for the invitation.
2. Accept the invitation to join the MTEC 3501 Zotero Library.
3. Open Zotero Desktop and verify that the shared library appears in the left sidebar.

### 2. Create Your Project Research Collection

Create a collection in the shared MTEC 3501 Zotero Library for your project.

1. Select the MTEC 3501 group library in Zotero Desktop.
2. Click the green **New Collection** button.
3. Name the collection `MTEC3501-YourName` (for example, `MTEC3501-SmithDavid`).
4. Use this collection for sources related to your Culmination Project.

### 3. Add an Initial Project-Relevant Source

Save at least one source related to your emerging project interests in your collection. A source may be an artist or designer, an existing project, a technical method, a technology, an interaction model, or a cultural or social context.

1. Use the Zotero Connector to save the source to your collection.
2. Check that the bibliographic information is correct.
3. Add a short note explaining why the source is relevant to your project.

### 4. Prepare for Project Tracking

Project tracking will begin next week. For now, make sure you can access
your personal repository and identify one likely next project task.

1. Go to your personal repository on GitHub.
2. Confirm that you can access the **Issues** and **Projects** tabs.
3. Write down one likely next project task to use when project tracking is introduced.

### 5. Project Tracking Next Week

Create the first GitHub Issue and Project Board during next week's project
tracking activity.

## Deliverables

By the end of Week 2, your Zotero setup should include:

- Access to the MTEC 3501 shared Zotero Library
- A personal project research collection in that library
- At least one project-relevant source with a short relevance note
- Repository access confirmed and one likely next project task identified

GitHub Issue and Project Board setup are deferred to next week.

## If You Are Waiting for Access

Do not create a second Zotero account. Confirm that you submitted the correct Zotero handle in the Week 1 Onboarding Information Form, then post in the Discord Support channel if you need help. You may gather possible sources while you wait, but save them to the shared collection once your access is available.
