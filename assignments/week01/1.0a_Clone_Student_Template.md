# Week 1 — Creating & Cloning Your Personal Repository from the Student Template

This document gives you the **complete, explicit, step-by-step directions** for creating your own MTEC 3501 repository from the class template and getting it onto your computer. Follow every step in order — do not skip ahead.

**Student Template URL:**
👉 https://github.com/entertainmenttechnology/MTEC3501-Student-Template

---

## Before You Start — Requirements

You must have already completed the following (see [1.1 Onboarding](1.1_Onboarding.md) if you have not):

- [ ] A GitHub account exists and you can log in
- [ ] Your GitHub username follows the course specification:
  - Includes your **last name** and at least your **first initial**
  - Lowercase letters and hyphens only (no spaces, no special characters other than `-`)
  - Examples: `smith-david`, `nguyen-a`, `johnson-maria`
  - If taken, add a single digit: `smith-david2`
- [ ] You have a custom profile picture set on GitHub
- [ ] You have submitted your GitHub username via the GitHub Onboarding Form (so your instructor can grant you access)
- [ ] GitHub Desktop **or** Git command line is installed on your computer
- [ ] VS Code is installed on your computer

If any of these are missing, stop and complete [1.1 Onboarding](1.1_Onboarding.md) first.

---

## Step 1 — Open the Student Template

1. Open a web browser and go to:

   ```
   https://github.com/entertainmenttechnology/MTEC3501-Student-Template
   ```

2. Make sure you are **logged into GitHub** with the account you registered for this course.

3. **Do not** click the **Fork** button. **Do not** click **Code** and clone this repository directly. This is a template — you must generate your own copy of it (see Step 2). Editing or cloning the template itself will not create a repository that belongs to you.

---

## Step 2 — Generate Your Own Repository from the Template

1. On the template page, click the green **"Use this template"** button (near the top right, next to the **Code** button).
2. Choose **"Create a new repository"** from the dropdown.
3. On the "Create a new repository" screen, set the following:

   **Owner:** Your personal GitHub account (make sure it is *not* set to an organization unless your instructor tells you otherwise).

   **Repository name:** Use this exact naming pattern:

   ```
   MTEC3501-<your-github-username>-2026F
   ```

   Example: if your GitHub username is `smith-david`, your repository name should be:

   ```
   MTEC3501-smith-david-2026F
   ```

   **Description (optional):** You may add a short description, e.g. "MTEC 3501 Culmination Project — David Smith."

   **Visibility:** Select **Public**. (Public allows the instructor and classmates to view and comment on your work without requiring separate access grants. If you have a specific reason you need it Private, ask your instructor before proceeding.)

4. Leave **"Include all branches"** unchecked (default).
5. Click the green **"Create repository"** button.

GitHub will now create a brand-new repository under your own account, pre-loaded with the template's files. This is now **your** repository — separate and independent from the template.

---

## Step 3 — Confirm Your New Repository Exists

1. You should be automatically redirected to your new repository. The URL will look like:

   ```
   https://github.com/<your-github-username>/MTEC3501-<your-github-username>-2026F
   ```

2. Confirm:
   - The repository name matches what you entered in Step 2
   - The files from the template (README, folders, etc.) are present
   - Your GitHub username appears as the owner (top-left, before the repository name)

**Do not proceed until this repository exists and is visible under your own account.**

---

## Step 4 — Clone the Repository to Your Computer

You only need to do **one** of the two methods below (GitHub Desktop is recommended for beginners).

### Option A — Using GitHub Desktop (recommended)

1. On your new repository's GitHub page, click the green **Code** button.
2. Click **"Open with GitHub Desktop"**.
3. GitHub Desktop will open and show a "Clone a repository" dialog with the correct repository already selected.
4. Choose (or confirm) a **Local Path** on your computer — a location you can find easily, e.g. `Documents/GitHub/`.
5. Click **"Clone"**.
6. Wait for the clone to finish. GitHub Desktop will show your repository as the "Current Repository."

### Option B — Using the command line (Git / Terminal)

1. On your new repository's GitHub page, click the green **Code** button.
2. Under **HTTPS**, click the copy icon to copy the URL. It will look like:

   ```
   https://github.com/<your-github-username>/MTEC3501-<your-github-username>-2026F.git
   ```

3. Open a terminal window.
4. Navigate to the folder where you want to store your repositories, for example:

   ```bash
   cd ~/Documents/GitHub
   ```

5. Run:

   ```bash
   git clone https://github.com/<your-github-username>/MTEC3501-<your-github-username>-2026F.git
   ```

6. Once cloning finishes, move into the new folder:

   ```bash
   cd MTEC3501-<your-github-username>-2026F
   ```

---

## Step 5 — Verify the Clone

1. Open your file explorer (Finder on macOS, File Explorer on Windows).
2. Navigate to the folder you selected in Step 4.
3. Confirm a folder named `MTEC3501-<your-github-username>-2026F` exists and contains the template's files (README.md, folders, etc.).

If the folder is empty or missing, the clone did not complete — repeat Step 4.

---

## Step 6 — Open the Repository in VS Code

1. Open VS Code.
2. Go to **File → Open Folder…**
3. Navigate to and select your `MTEC3501-<your-github-username>-2026F` folder.
4. Click **Open**.
5. Confirm your repository's files appear in the left-hand Explorer panel in VS Code.

You are now ready to begin editing your repository as instructed in the remaining steps of [1.0 Week 1 Class Session](1.0_Week01_Class_Session.md).

## Common Problems & Fixes

| Problem | Likely Cause | Fix |
|---|---|---|
| "Use this template" button is missing | You are not logged in, or viewing on a mobile browser | Log in to GitHub on a desktop browser |
| Repository was created under an organization instead of your account | Wrong **Owner** selected in Step 2 | Delete the repository and redo Step 2, choosing your personal account as Owner |
| Cloned folder is empty | Clone did not finish, or wrong repository was cloned | Delete the folder and repeat Step 4 with the correct repository URL |
| GitHub Desktop doesn't show your repository | Not logged into GitHub Desktop with the correct account | Go to **File → Options → Accounts** (Windows) or **GitHub Desktop → Preferences → Accounts** (macOS) and sign in |
| You accidentally cloned the **template** itself instead of your copy | Clicked **Code** on the template page instead of "Use this template" | Delete that folder, return to Step 1, and follow Step 2 exactly |

If you are still stuck, post in the Week 1 Discord channel with a screenshot of the error.

## Quick Reference Summary

1. Go to https://github.com/entertainmenttechnology/MTEC3501-Student-Template
2. Click **Use this template → Create a new repository**
3. Owner = your account; Name = `MTEC3501-<your-github-username>-2026F`; Visibility = Public
4. Click **Create repository**
5. Click **Code → Open with GitHub Desktop** (or copy the HTTPS URL and `git clone` it)
6. Choose a local folder and clone
7. Open the cloned folder in VS Code
