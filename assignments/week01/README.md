# Week 1 — Course Launch

Week 1 is a guided asynchronous online class. Work through the steps below in order. Use the scheduled class period as your launch time and complete remaining work independently during the week.

**All Week 1 activities must be complete before the Week 2 face-to-face class.**

> **Your systems should be ready. Your project should be ready to change.**

---

## Step 1 — Welcome

Read the [course README](../../README.md) for an orientation to the course, its framework, and your semester roadmap.

---

## Step 2 — Join Discord

Create or verify your Discord account and join the class server.

**Invitation link:** https://discord.com/invite/9qSjqDKWyB

- Set a recognizable course nickname (First Name Last Name or equivalent).
- Find the Week 1 channel and post your response to the opening prompt:

> *What is one of the coolest, strangest, most exciting, or most unsettling new technologies, media developments, creative practices, or cultural shifts you have encountered recently? It can be something you want to work with, something you are skeptical about, or simply something you find difficult to stop thinking about.*
>
> Post your name, your response, and reply to at least one classmate with a question, connection, disagreement, or related example.

Discord remains available throughout the week for questions and peer troubleshooting.

## Step 5 — Project Development Concepts

Read the [Project Scale section](../../README.md#project-scale) of the course README to understand the three scales of your project:

- **North Star Vision** — what the project might ultimately become
- **Minimum Viable Product (MVP)** — the smallest meaningful realization that still functions as the intended project (target for ENT 4501)
- **Proof of Concept** — what you need to demonstrate this semester in MTEC 3501

These definitions are provisional. You will refine them throughout the course.

## Step 6 — GitHub Setup

### 6a. Create or verify your GitHub account

- Use an identifiable username (include your name).
- Add a custom avatar.

### 6b. Submit your GitHub username

**Submission form:** [GOOGLE FORM LINK TBD]

*Note: some GitHub access requires instructor authorization after usernames are collected. Steps that need authorization are marked below. Continue with other steps while you wait.*

### 6c. Create your personal MTEC 3501 repository

Create a new repository from the Student Project Repository Template:

**Template:** https://github.com/entertainmenttechnology/MTEC3501-Student-Template

- Use **"Use this template"** — do not fork or clone the template itself.
- Name your repository clearly: `MTEC3501-<your-github-username>-2026F` (e.g., `MTEC3501-smith-david-2026F`).
- Set visibility to **Public**.

For complete, explicit step-by-step directions (including troubleshooting), see [1.0a Clone Student Template](1.0a_Clone_Student_Template.md).

### 6d. Clone your repository locally

Clone your new personal repository to your computer using VS Code or GitHub Desktop. See [1.0a Clone Student Template](1.0a_Clone_Student_Template.md) for full directions.

### 6e. Open in VS Code

Open the cloned repository folder in VS Code.

### 6f. Edit your README

Update your `README.md` with:

- your name and GitHub username
- a working project title
- a short description of your current concept

### 6g. Complete your Initial Project Speculation document

Open `docs/01_speculation/01_Initial_Project_Speculation.md` and fill in your responses. You may write directly in the file or compose elsewhere and paste in.

### 6h. Start your Project Log

Open `project-log.md` and add your Week 1 entry.

### 6i. Commit and push

Commit your changes with a clear message (e.g., `Week 1 initial setup`) and push to GitHub.

### 6j. Verify online

Open your repository on GitHub and confirm your changes appear.

### 6k. Create your first Issue

Create a GitHub Issue titled:

> `Complete MTEC 3501 Week 1 Onboarding`

### 6l. Create your initial GitHub Project

Create a GitHub Project with three columns: **Backlog / In Progress / Done**.

Move your onboarding Issue to In Progress.

## Step 8 — Exploratory Research

After completing the Initial Speculation Form, exploratory research is encouraged.

You might look into: a technology, an artist working in a related area, an existing project, a technique, or a social/cultural context. Research may confirm your assumptions — or cause you to revise them. Both outcomes are useful.

Add sources to Zotero as you find them.
