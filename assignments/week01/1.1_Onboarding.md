## Supports Step 11 — Set Up GitHub Account

**Purpose:** Repository for project materials, version control, and collaborative coding.

**Actions:**
1. Create an account or confirm your existing account: https://github.com/join
2. Choose a username that meets the specification below
3. **Upload a custom profile picture** to your GitHub account. [Learn how to personalize your profile](https://docs.github.com/en/account-and-profile/tutorials/personalize-your-profile). Using a distinctive profile picture across platforms aids in visual identification and makes collaboration easier.
4. Do **not** share your password, tokens, or recovery codes with anyone.

**GitHub Username Specification (must follow — this is the official spec; it supersedes any looser description elsewhere):**
- Your GitHub username must clearly identify you. It must include your LAST NAME and at least the initial of your FIRST NAME.
- Use only lowercase letters and hyphens. No spaces, special characters (except `-`), or unusual punctuation.
- Preferred formats (examples):
  - `smith-david`
  - `nguyen-a`
  - `johnson-maria`
- If your preferred handle is already taken, add a single digit suffix, e.g. `smith-david2`.
- Do NOT use handles that obscure your identity (no emoji-only handles, nicknames only, or handles that are likely to confuse instructors/peers).

**Why this matters:**
- Clear, consistent usernames let instructors add repository write access and find student branches easily.
- Using a canonical format helps automated grading, roster linking, and archiving at semester end.
- This exact username is what you'll submit in Step 12 and use for your repository name in Step 15 (see [1.0a Clone Student Template](1.0a_Clone_Student_Template.md)).

## Supports Step 13 — Install & Verify GitHub Desktop or Git

1. Download and install **GitHub Desktop**: https://desktop.github.com/ (recommended for beginners), **or** install command-line Git if you prefer the terminal.
2. Sign in to GitHub Desktop with the GitHub account you set up in Step 11.
3. Configure your identity (GitHub Desktop does this automatically on sign-in; for command-line Git, run `git config --global user.name "Your Name"` and `git config --global user.email "you@example.com"`).
4. Test that it's working: open GitHub Desktop and confirm you are signed in, or run `git --version` in a terminal.

## Supports Step 18 — Editing Your README

Once your repository is cloned and open in VS Code (Steps 15–17):

1. In the VS Code Explorer panel, click `README.md` to open it.
2. Edit the file directly in the editor, replacing the placeholder content with:
   - Your name
   - GitHub username
   - Working project title (provisional)
   - Current project description (2–3 sentences)
   - Possible project type(s) (game, installation, software, etc.)
   - Possible project origin (student-originated, existing, CHI Meta-Project, etc.)
   - One important question or uncertainty
   - Any relevant links or resources
3. Save the file: **Cmd+S** (macOS) or **Ctrl+S** (Windows).

## Supports Step 19 — Commit & Push Your Changes

After saving your README (or any file):

1. Open **GitHub Desktop**. It should automatically detect your repository and list the changed file(s) on the left.
2. Confirm the changes shown match what you edited.
3. In the **Summary** field at the bottom left, write a short commit message (e.g., "Initial README setup").
4. Click **Commit to main**.
5. Click **Push origin** (top toolbar) to upload your commit to GitHub.
6. Go to your repository on GitHub.com and refresh the page to verify your changes appear online.

**Command-line alternative:**

```bash
git add README.md
git commit -m "Initial README setup"
git push
```

This edit → commit → push cycle is the core Git workflow you'll repeat throughout the semester.

## Supports Step 20 — Set Up Zotero Account

**Purpose:** Collaborative reference management and citation sharing for research.

**Actions:**
1. Create an account on Zotero: https://www.zotero.org/user/register
2. Download and install **Zotero Desktop**: https://www.zotero.org/download/
3. Install the Zotero browser Connector for your browser.
4. Configure your desktop app to sync with your online Zotero account and confirm it's working.

**Zotero Username Specification:**
- Use a clear, professional username.
- Examples: `smith-david_research` or `smith-d_2026`.
- If possible, duplicate the same name as you used for GitHub.

**Note:** Joining the shared course Zotero group library requires instructor authorization after usernames are collected, and will be completed in the Week 2 class — you do not need it for Week 1.
