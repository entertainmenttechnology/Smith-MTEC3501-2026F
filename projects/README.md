# Student Projects

Each student maintains an individual subfolder here (e.g. `projects/YourName/`) containing their working materials for the semester: speculative writing, research, proposals, and other deliverables.

> **Note:** As of the MTEC 3501 Student Project Repository template, students maintain their own individual repositories rather than a subfolder in this class repository. This folder is retained here for classes that still use the shared-repository / branch-per-student workflow.

Create your folder using your name (e.g. `projects/LastName-FirstName/`) and commit your work there on your own branch.
